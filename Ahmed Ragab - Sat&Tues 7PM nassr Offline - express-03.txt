event loop is the core of nodejs that allows it to run async non blocking code by taking tasks from queue to stack when it is empty.
//     =Q1=
//
//     libuv is a c library nodejs uses to handle async operations like file system and networking using thread pool and event loop.
//     =Q2=
//
//     nodejs sends async tasks like file reading or network requests to libuv or operating system and when done callback is sent to queue.
//     =Q3=
//
//     call stack executes sync code, event queue holds callbacks waiting to run, and event loop moves callbacks from queue to stack when stack is clear.
//     =Q4=
//
//     thread pool is used by libuv to do heavy work off the main thread, and we change size by UV_THREADPOOL_SIZE environment variable.
//     =Q5=
//
//     blocking code stops execution of next code until it finishes, while non blocking lets code run asynchronously without waiting.
